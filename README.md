# Aurora

Aurora is a compact Android browser prototype inspired by the speed and privacy ethos of browsers such as Bromite, but built with its own **bottom-dock “spaces” UI** rather than a Chromium-style top toolbar.

## Highlights

- Address/search field with URL detection and Google search fallback
- Multiple tabs, a visual tab-space chooser, and one-tap private-tab mode
- WebView navigation controls, page title/progress, sharing, find-in-page, and reload
- Safe Browsing, HTTPS-first navigation, disabled mixed content, and a clear-data action
- Clean original dark/mint design with a calm start screen

## Build

Open the project in current Android Studio, let it install the Android Gradle Plugin dependencies, and run on an Android 8.0 (API 26) or newer device/emulator.

> This is a browser shell based on Android System WebView. It is not a fork of Chromium/Bromite and therefore cannot include Chromium-level features such as extension support or a bundled ad-blocking engine.
